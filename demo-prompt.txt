Create a Flask web app in one shot for "Knight Hacks IX Strategist", styled after the official Knight Hacks IX website (2026.knighthacks.org).

## Event Context:
Knight Hacks IX is the University of Central Florida's premier annual 36-hour hackathon in Orlando, FL (October 9 - 11, 2026), bringing together over 1,000+ hackers to build, learn, and create together as Florida's best hackathon. The theme is an enchanted woodland / mystic twilight forest filled with ancient runes, fireflies, and mystical woodland creatures.

## Mobile-First & Responsive UX:
- Optimized primarily for mobile phones (single-column, no horizontal overflow, 44px+ touch targets).
- Clean desktop expansion (max-w-4xl, centered layout).
- Tap-friendly track and prize selectors with active glowing state.
- Sticky/accessible bottom chat input bar with auto-scrolling message container.

## Technical Requirements:
- Python Flask backend with Google Gemini (`model="gemini-flash-lite-latest"`).
- Frontend: Tailwind CSS (CDN) + AJAX (fetch) without full page reloads.
- Use Python `markdown` package to render Gemini responses into clean HTML.

## App Workflow:
1. User selects 1 Knight Hacks Track and multiple MLH Prize Categories.
2. User taps "Generate Idea" (shows enchanted forest / firefly-themed loading state).
3. Gemini crafts a tailored project idea integrating technologies for each selected prize and explaining relevance to the chosen track.
4. Unlocks interactive chat to brainstorm and drill into implementation details with Lenny & Keyboard Koala.

## Persona (Lenny & Keyboard Koala):
- Name: Lenny & Keyboard Koala (Knight Hacks & MLH Mascots)
- Role: Elite hackathon mentors & coaches (veteran champions with 20+ hackathons under their belt).
- Tone: High-energy, encouraging, tactical, and mystical. Delivers concise, actionable, mobile-scannable advice (avoid tables).
